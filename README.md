## 项目概况

- 线上产品：[UI工作室](https://layerlab-studio-dany.xpbet-3575.chatgpt.site/)
- 本次迁移基准：线上 **V6**（以此前成功发布记录为准）
- 目标：将原「Icon 生成工作台」和「AI 图像生成」合并为 **AI创作台**
- 主要用户场景：体育 / Casino 宣传图、图标、活动素材与参考图编辑

## 下一版本唯一创作流程

1. 输入自然语言需求
2. 上传参考图（可选择造型、材质、构图等参考角色）
3. 自动提取并核对生成要求
4. 调用真正的图像生成模型
5. 通过自然语言连续修改并恢复版本
6. 下载 PNG / 透明 PNG（验证尺寸和实际 Alpha）

**不再把预设 3D 图标拼装或本地材质建模作为默认生图方式。**

## 已知线上 V6 功能（非本仓库所包含的代码）

- 旧 Icon 生成工作台（本地预设模型）
- UI 页面工作区（主站首页 / 活动页面 / 自由模板）
- 图片拆层、作品库和导出
- 静态素材和部分 Figma 设计变量读取结果

新 AI创作台尚未完成真实模型调用。ChatGPT 订阅不能替代网站 API 额度或凭据。
