# UI工作室 · AI创作台

Icon 与图像已合并到 `/studio/#creator`；`#icons` 和 `#image` 会进入同一创作台。

## 当前生成方式

所有新生成默认且仅使用已登录的豆包桌面端。流程是：网页输入 → 本机连接窗口 → 豆包免费日常模型 → 原图下载到本机 → 回到网页。前端没有付费生成选项，后端默认拒绝新付费调用。不会因额度、超时或失败自动切换服务商、购买套餐或调用透明提取。

- 保持豆包打开并登录，运行根目录的“连接豆包桌面.cmd”，在网页点“连接豆包桌面”。连接窗口须保留。
- 连接器只监听 127.0.0.1:9231，桌面调试连接只使用 127.0.0.1:9229。仅已登记的工作室来源可连接，不导出 Cookie、密码或账号凭据。
- 支持文字生图、最多3张参考图及用途、指定基图修改。原始需求、父版本和参考文件指纹保留。任务发送前写入记录；超时只能恢复检查，不自动重发。
- 免费额度、模型可用性和输出分辨率以豆包客户端为准。客户端可能输出2K带标识图片，不能强制变为低分辨率计费；本工作室没有付费 API 用量。
- 文件核对尺寸、可解码性、有效像素和真实透明像素。豆包可能忽略材质、精确文字或透明要求，页面会提示已知输出缺口；模型语义仍需对照原需求核验。保留客户端原有标识。
- 豆包的未发送草稿、正在处理的任务、登录或额度提示都会使连接器停止，不覆盖、不购买。ComfyUI 仍保持停止状态。

## 按你的组件与变量生成 UI

打开 `/studio/#ui` →“需求生成”。输入需求或导入 TXT / Markdown PRD，可加 PNG/JPEG/WebP 参考图。豆包免费快速模式只返回受约束的页面方案；本地校验后由固定渲染器生成 HTML，不执行模型代码。

- 使用真实 Figma 的110项变量、16种 Poppins 文字样式。已按高清原稿接通19类组件及其变体：按钮、输入框、下拉、复选、单选、开关、标签页、侧栏导航、品牌导航、表格、分页、FAQ、内容面板、提示、进度、状态标签、弹窗、空状态、辅助说明。节点、素材和适配边界见 `public/studio/figma/executable-components.json`。导入或手动绑定的设计系统变量也会应用并记入清单。
- 可组合这些组件生成完整页面；支持本地搜索、筛选、排序、分页、标签切换、表单校验、弹窗和控件状态。可复用21个已归档桌面区块和2套完整原稿，保留原始素材、节点与比例。原稿区块不冒充自适应手机组件；浅色模式不会改画原有插画。
- 无效方案最多在同一豆包免费快速对话中修正两次，每次发送前保存账本；只读取本次原始需求与登记修正对应的回复。仍不合格则停止并保留现有页面。
- 新页面使用受约束的组件树，缺少要求中的组件、文案、有效目标或变量时停止替换现有版本。原稿首屏允许修改已登记的标题、副标题、按钮文案，未接通的组件、交互或内容改动必须列为缺口。档案中的数千条组件记录不代表全部完成可执行映射。
- 支持 Dark/Light、390/768/1440/1600宽度、参考图布局解读、在上一版基础上自然语言修改、历史版本及离线 HTML 导出。每版保留需求、组件节点、变量模式、参考来源和缺口。
- 原始需求、参考图会发送到用户已连接的豆包桌面服务理解。导出的是前端 UI 原型，真实业务提交、账户与数据服务需另行连接。
- “原稿区块”保留无需模型的原稿组合入口；主站、活动、原始作品与组件档案继续保留。

## 花瓣参考连接

`desktop/huaban-extension` 是本地开发的 Chrome 扩展，商店中搜不到。桌面副本名为“UI工作室-花瓣参考连接”。需用户手动在 chrome://extensions/ 开启开发者模式、加载该文件夹，再在扩展中点“连接并检查任务”。

扩展在已登录 Chrome 中读取花瓣可见搜索结果，下载用户选中的实际图片，回传“灵感素材库”，可发送到图像创作或 UI 需求。权限仅花瓣页面/图片、本机连接器、定时检查与扩展状态。可接收指定工作室网页的本机连接请求；不读取其他网页，不导出登录信息。只使用自己的后台工作标签。遇到登录、验证或403会停止，需用户在花瓣处理，不绕过校验。

扩展已提供搜索、图片回传和来源校验；只有完成用户 Chrome 的真实搜索与下载，才能视为实际接入验收通过。模拟通信测试不代表花瓣已可访问。

## 运行与验证

Node.js 22.13+、pnpm 11.25.0。依赖已安装时直接运行 `pnpm run dev`，打开终端所示地址的 `/studio/`。构建用 `pnpm run build`。

检查：`node scripts/check.mjs`；回归：`node --test tests/*.test.mjs`；密钥扫描：`node --env-file=.env.local --env-file=.env.ark.local scripts/check-secrets.mjs`。测试使用模拟模型检查安全边界与防重，实际免费生成的验收另见工作区“验收结果”。

## 安全与旧 API

`.env.*`、本机任务、图片、参考与会话均不提交源码。生产维持现有私有访问权限和数据绑定。旧付费任务仅保留查询恢复；旧 API 代码只有部署环境明确开启 `CREATOR_PAID_API_ENABLED=true` 或 `PAID_UI_API_ENABLED=true` 才接受新请求，当前不得启用。浏览器参数不能绕过关闭状态。已有服务端密钥不显示、不迁移到前端、不写入扩展。

桌面自动化依赖客户端可见控件；客户端更新可能需要维护。缺少本机连接时，托管网页无法独立操作这台电脑。
