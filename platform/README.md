# UI工作室 · 可独立运行的重建版

根据用户指定的线上平台重建，保存了原站仍公开提供的前端程序、样式、图片、字体和 Figma 设计快照。可直接编辑 `dist/` 内的代码，无需安装第三方依赖。

## 本地运行

安装 Node.js 20 或更高版本后，在这个目录运行：

```sh
npm run dev
```

打开 http://127.0.0.1:4173/studio/#start 。运行 `npm run check` 检查脚本语法和静态资源完整性。

## 已保留的工作区

- 工作室首页及原有紫色视觉系统。
- 3D Icon 工作台：主体、材质、装饰、图层、撤销、PNG 和项目导出。
- 图片拆层：示例或本地图片、自动与手动选区、图层和分层文件导出。
- UI 页面：Megwin 主站和活动原稿快照、文案修改、Dark/Light 变量预览、ZIP/HTML 导出及自由模板。
- 组件与变量：原站设计读取快照、浏览、导入和导出。
- 灵感素材库和当前浏览器的作品库。

## 服务状态和恢复范围

这是一份基于已发布前端的可运行重建，不是遗失的服务端仓库或历史版本备份。原站公开的前端及静态素材已保存在本项目，不依赖原站继续存活。

AI 图像、AI 文案和 Figma 在线同步的原服务端代码、密钥及用户云端数据无法由公开网页恢复。AI 功能保留“未配置”状态，不会用示例图伪装生成结果。Figma 原有设计快照可在本地继续使用；线上同步需要另行实现授权服务。作品库和草稿保存在当前域名的浏览器内，旧域名的本地作品不会自动迁移。

`dist/api/studio/status` 提供准确的服务状态；`scripts/serve.mjs` 是本地预览服务器。重新接入 API 时，密钥应配置在服务端。

## 文件

- `dist/studio/`：工作室页面、模块、3D 引擎、Figma 快照与素材。
- `dist/splitter/`：独立图片拆层工作台。
- `recovery-manifest.json`：公开文件恢复记录；其中 404 项也可能是生成的下载文件名、原代码中的文档示例或原站本来就不存在的路径，不代表页面依赖缺失。
- `recover-public.mjs`：一次性恢复工具，不参与网站运行。
- `.openai/hosting.json`：本次重建的新 Sites 项目身份。
