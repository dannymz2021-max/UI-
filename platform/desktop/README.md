# 豆包桌面连接

双击项目根目录的 `连接豆包桌面.cmd`，保持豆包已登录并显示主窗口。回到 AI创作台点击「连接豆包桌面」，填写需求并生成。浏览器如询问访问本机网络，允许这个工作室网站即可。

默认使用 Seedream 4.5 日常模式，沿用用户选择的免费套餐；可用次数以客户端为准。连接器不充值、不购买套餐、不自动切换到方舟 API。网页与本机通过 127.0.0.1:9231 通信，桌面连接为 127.0.0.1:9229。请勿把这两个端口转发到外网。

当前自动流程支持文字生图，每次一张。参考图和基图编辑在连接器提交前拒绝，不会忽略图片继续生成。可在豆包完成后用「导入生成结果」保存。原图的水印保留；尺寸、透明像素按实际文件检查，不承诺桌面端支持任意尺寸或透明输出。

只有指定工作室网站和本机 5173 预览页能够建立连接。会话凭据仅在进程和网页内存中。任务账本与图片保存在 `.sites-runtime/desktop-bridge/`，不进入源码提交或部署包。连接器只读取界面及本次图片，不读取 Cookie、登录凭据或内部应用状态。

任务在发送前写入账本，重复编号只查询；连接中断、超时、重启不会自动重发。保持本次豆包对话打开，使用「检查上次任务」恢复。如一直未返回，请先在豆包核对原任务。关闭本机连接器会停止网页连接，不影响已有作品。

开发验证：`node --test tests/desktop.test.mjs`。无需安装新依赖。需要 Node.js 22+（内置 WebSocket）。桌面界面改版时可能需要更新控制选择器；只在已核对的 Seedream 4.5 模式发送。
