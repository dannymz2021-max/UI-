# 统一 AI创作台 — 功能范围

## 统一入口 / 唯一流程
**输入需求 → 上传参考图 → 系统理解 → AI 生成 → 自然语言继续修改 → 下载 PNG / 透明 PNG。**

图片与 Icon 仅是用途不同，不是两套独立工作台。删除需要手工建模的生成主流程；保留必要的作品、图层拆解和原站 UI 等其他模块。

## 需求解释
记录用户原文，解析任务类型、主体、数量、尺寸/比例、参考图使用范围、视觉风格、材质、灯光、构图、准确文字、背景、禁止项。只在无法合理推断且显著影响结果时简短确认。不要擅自加入金币、皇冠、人像、Logo 或文字。

## 参考图
支持外形 / 光影材质 / 构图 / 指定原始素材的不同用途。不能将未经核实的花瓣搜索结果视为可用素材，也不能未经授权收集、分发第三方作品。

## 生成与连续编辑
模型在服务端调用并保留原始图和每次修改版本。记录请求ID（若可用）、模型、可验证文件属性及错误信息。不要声称 ChatGPT 当前账号额度可直接用于网站 API。

## 下载与检验
下载真实 PNG；透明 PNG 需有效 Alpha 通道且主体非空。验证宽高、文本准确性、无误裁切、不拉伸。输出尺寸超出模型原生规格时采用有说明的适配策略。

## 安全
公开站必须限制匿名生成，实施登录、配额、限流、异常重试策略和费用可控。API Key 仅在服务端变量中配置，日志不得泄露密钥。
